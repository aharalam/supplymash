# SupplyMash interface direction

The existing Next.js application is a business workspace. The interface foregrounds real orders, materials, quantities, and next actions; it does not invent impact metrics or represent planned backend capabilities as live.

Typography: locally served DM Sans variable, restrained 32–48px page titles, 22–28px section titles, 14–17px body/control text. Ivory canvas, forest text and actions, muted sage review surface. Status text uses darker accessible tones. Shared navigation and footers align with 1248px content; mobile gutters are 24px.

Homepage: live network totals, open pools, pending matches with matching action, active exchange listings, and storage link. No decorative hero, imaginary activity, or oversized marketing panels. Existing workflows remain in place. Motion is confined to hover/focus/press feedback with reduced-motion support.

Verification: production build passes. Browser screenshots remain unavailable because the native/browser host is disconnected; no visual QA claim is made. The new order-first API remains a separate backend integration milestone.
