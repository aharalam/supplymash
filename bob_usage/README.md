# Bob Usage Screenshots

This folder must contain IBM Bob IDE budget usage screenshots for each team member before submission.

**Required by the hackathon:** Upload evidence of IBM Bob IDE usage to this folder.

## Instructions

1. In IBM Bob IDE, hover over the **Budget badge** in the top-right corner of the Bob chat interface.
2. Take a screenshot showing your Bob budget usage.
3. Save it as a PNG file with the naming convention:

```
teamname_midevfest26_IBM_Bob_usage.png
```

Example: `supplymash_midevfest26_IBM_Bob_usage.png`

4. Add the screenshot file to this folder and commit it before final submission.

---

Each team member should upload their own screenshot to ensure full team coverage.
